# Standard 证据门禁修复验收

- 日期：2026-10-19。
- 范围：`standard`，版本 `2.4.0-dev.3`，基线 `b13a23e`。
- 不修改其他版本分支或现有 CUMCM B 题示例；不创建 Tag/Release，不调用付费模型。

## 修复内容

1. 结果、指标、结论和图表改用成功状态白名单；`FAIL`、未知状态、缺状态及矛盾字段不能进入正式写作。
2. 指标必须为有限数值，不接受文本数字或布尔值。
3. 正式图表须可读取且绑定对应问题实际运行的输出哈希；代码、输入、输出和图表变更使旧 S6 PASS 失效。
4. 自动规划的图表及数据画像保留待复核状态。原始列不能直接冒充敏感性实验；探索标记不能仅靠修改状态消除。补齐“热图”类型识别。
5. 无可靠问题标题、DOCX 公式/OLE/图片或不完整 PDF 提取会触发源文档复核。Agent 核对原件后记录与当前分析绑定的复核，不增加用户检查点。
6. 门禁 `policy_version=2`，写作和 Word 导出拒绝沿用旧策略 PASS；升级不会自动改写旧证据。
