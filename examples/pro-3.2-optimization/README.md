# 可复算的优化论文样例

[PDF](final_paper.pdf) · [Word](final_paper.docx) · [正式源稿](final_paper_source.md)

这是四站点、五客户的**作者构造算例**，不是历年获奖论文或真实企业数据。
最优成本110.00、全部营业166.00、需求增加20%后重优化128.80，均由真实MILP和
独立穷举得到。文章区分“站点集合不变”与“原客户分配仍然可行”。

论文完成两轮、五个真实隔离上下文的审稿；首轮两项Minor修订后复审通过。
正式PDF共五页，20个Word原生公式（含行内公式），一张由指标生成的双图、三张表；
已逐页实际查看，DOCX/PDF与最终门禁均通过。

**测试边界：** P1读题及用户检查点是明确标识的自动化测试模拟，不能当作真实用户
审批。求解、复跑、独立审稿及逐页检查实际发生。此样例不认证特定模型的真实赛题
能力，不代表完整跨平台、跨模型或竞赛前向评估。

输入及两份实现见仓库 `tests/fixtures/forward/optimization/`，复现实验入口见
`scripts/run_forward_benchmark.py --help`。该开发脚本不进入Skill安装包，也不会自动
生成假审稿或视觉PASS。完整说明见 [验收记录](../../docs/pro-3.2-validation.md)。
